# v0.3.x 系列规划：对齐 Wails v3 / Tauri 2 剩余差距

> 制定日期：2026-11-16。基线：Zilt v0.3.1（git b08fdfc）。
> 对标版本：Wails v3.0.0 stable（2026-10-26 发布，v3 主线源码逐文件核对）、
> Tauri 2.12.6（2026-11-16，均为 bugfix，核心面与 2.12.5 一致；WindowConfig 58 字段 +
> Window 方法 120+ + 官方插件 workspace 31 插件逐一比对）。
> 范围决策（2026-11-16 用户确认）：**v0.3.2 纳入 P0 全部；四个大工程项
> （CompositionController / server 模式 / isolation pattern / 原始二进制 IPC）全部纳入 v0.3.x 排期**。
> 规划原则：沿用「一个版本一个主题 + 全链路验收」的节奏；平台差异显式文档化；
> 每项给出实现路径与验收标准，实施时允许实测后微调。

## 0. 差距分析结论速览

### 0.1 Zilt 已持平/领先的维度（不动作）

| 维度 | 证据 |
|---|---|
| 窗口基础/精细控制 | v0.1.18 + v0.3.0 后与 Tauri 基本同级 |
| 剪贴板 4 格式 + 拖入/拖出/坐标/自定义格式 | 领先 Wails（JS 层仅 Text/SetText）与 Tauri（无拖出） |
| 对话框（含颜色/字体） | 两家均无颜色/字体 |
| 子 WebView + 数据分区 + eval | 对齐 Tauri unstable 多 webview |
| CDP 逃生口 / 截图 / 每请求头 | 两家均无 |
| capability ACL + scope + 运行时授权持久化 + 原型冻结 | 对齐（Tauri 粒度更细但模型一致） |
| 差分更新 zilt-patch + 健康回滚 | Tauri 2 无 delta；Wails 无 delta（仅 providers 多样） |
| MCP（HTTP+stdio+resources+prompts+工具级 ACL） | Wails 有 MCP（tools/eval）但无 resources/prompts/ACL |
| headless / WebDriver E2E / doctor / 热重启 dev | 对齐 |

## 1. 版本切片

### v0.3.2 — WebView 数据与协议面（P0 第一批）✅ 完成（2026-11-17，见 ROADMAP 实施记录）

目标：收掉 WebView 层所有「明确未做」项，数据面与 Tauri 对齐。

- **B1 Windows 真 scheme**：`Config.protocols` 在 Windows 上注册真 `scheme://`
  （`ICoreWebView2EnvironmentOptions4` 17 槽 vtable + `ICoreWebView2CustomSchemeRegistration`，
  AllowedOrigins 配置；伪路径协议保留为兼容回退）。
  验收：Windows 冒烟 `fetch('zilt-app://...')` 200/206/自定义头/POST 兜底语义（body 不可读的限制文档化）。
- **B2 无痕窗口**：`window.create({ incognito: true })` / `webviews.create({ incognito: true })`。
  Win：ControllerOptions.IsPrivate（独立 InPrivate controller）；Linux：ephemeral WebKitWebsiteDataManager
  （分区基建复用）。数据落盘断言：无痕会话退出后无新持久化目录。
- **B5/B6 设置开关面**：`Config.webview` / `webview.settings` 运行时 op——
  autofill / passwordAutosave / zoomControl（Win：Settings4/Settings3；Linux：文档化 NotSupported）。
- **B4 backgroundThrottling**：`window.create({ backgroundThrottling })`，Win 路径实测择一
  （AdditionalBrowserArguments `--disable-render-backgrounding` 等）；Linux 无标准 API → 文档化。
- **B7 screens 细化**：`system.info('monitors')` 增 work_area/current 标记；新增
  `window.state().monitor`（当前窗口所在显示器）与 `system.monitorOf(windowId)`；
  Win `MonitorFromWindow`/`GetMonitorInfo`，Linux `gdk_display_get_monitor_at_window`。
- **A13 电源/会话事件**：`powerSuspend / powerResume / powerStatusChanged / sessionLock / sessionUnlock`
  事件；Win：WM_POWERBROADCAST + WTS；Linux：GDBus login1 订阅。
  验收：单测（消息分类/载荷拼装）+ Win 实测睡眠往返或注入消息冒烟 + Linux CI 无总线明确 skip。

### v0.3.3 — 窗口体验包 II（P0 第二批）✅ 完成（2026-11-17；tint/cornerPreference 与 Linux KeyBindings 移至后续，见 ROADMAP 实施记录）

目标：窗口层对齐 Wails/Tauri 的剩余 UX 项，主攻「托盘弹窗类应用」场景。

- **A1 形状 mask**：`window.create({ mask: <asset path>, maskDraggable })`。
  Win：png.zig（已有）解码 alpha → SetWindowRgn（阈值化边界），maskDraggable → WM_NCHITTEST；
  Linux：cairo region → input shape。冒烟：异形窗口截图 + 点击区域断言。
- **A3 + A9 托盘附着窗口**：`Config.tray.attach_window = <window label>` 或运行时
  `tray.attach(windowId)`——点击托盘 → 定位显示（Win `Shell_NotifyIconGetRect`）→
  失焦/Escape 隐藏（`window.create({ hideOnFocusLost, hideOnEscape })` 作为通用窗口选项）。
  Linux 定位精度差异文档化。
- **A2 每按钮状态**：`window.create({ closable, minimizable, maximizable })` +
  运行时 `window.setButtonState(kind, state)`。Win 实装；GTK3 → NotSupported（文档化）。
- **A4 窗口级 KeyBindings**：`window.create({ keyBindings: [{accel, id}] })` → 事件
  `windowKeyBinding {id, windowId}`（复用 accel.zig/CreateAcceleratorTable/GtkAccelGroup）。
- **A5/A6/A7/A8/A10 小项合集**：`window.startResizeDragging(edge)`、
  `window.create({ preventOverflow })`、`setSimpleFullscreen` 别名（语义文档化）、
  `window.create({ titlebarDoubleClick: 'maximize'|'none' })`、`window.create({ moveDebounceMs })`。
- **A12 效果参数**：`appearance.apply({ tint, cornerPreference })`（Win：accent policy tint +
  DWMWA_WINDOW_CORNER_PREFERENCE；radius 文档化 macOS-only）。
- **C4 事件钩子**：Zig 侧 `ctx.onWindowEvent`（可取消 windowCloseRequested 默认行为）。

### v0.3.4 — 分发与更新（P0 第三批）

目标：发布链路对齐 Tauri/Wails 的分发完整度。

- **E1 侧车资源/sidecar**：`project.zig` 增 `resources: [_][]const u8`（目录/文件，
  保持相对结构）与 `external_bin: [_][]const u8`（按 target-triple 解析二进制）。
  NSIS/MSI/MSIX/zip/deb（/usr/lib/<app>/）/AppDir/AppImage 全格式同步打包；
  运行时 `path.resource(rel)` 返回安装路径；`process.spawn` 打通侧车执行。
  验收：pack E2E（安装后侧车文件存在 + 应用 spawn 侧车回显）。
- **E2 离线 WebView2 fixed E2E**：fixed 模式（`Config.environment.browser_directory`）
  打包 E2E——无 Evergreen 环境模拟 + 安装后运行冒烟。
- **E3 更新器事件协议 + skip version + GitHub provider**：
  - 事件面补全：`updateCheckStarted / updateAvailable / updateNotAvailable / downloadProgress
    (written/total ~10Hz) / downloadComplete / verifying / installing / updateReady / updateError`，
    JS `updater.on(...)`；语义对齐 Wails 命名但保持 Zilt 事件风格。
  - `updater.skipVersion(version)` → `<appData>/skipped.json`，check 时命中则报
    `updateNotAvailable(skipped)`。
  - provider：`manifest_url` 保持 + 新增 `provider = "github"`（GET releases/latest →
    按 channel/asset 规则匹配 manifest/安装包）；Fetcher 注入离线单测。
  验收：本地 http_echo 模拟 GitHub API 的 check→下载→staged E2E + skip 往返 + 事件序列断言。
- **E4 交叉编译 pack**：`zig build pack` 支持 `--target x86_64-linux-gnu`（deb/AppDir/AppImage
  可交叉产出；NSIS/MSI/MSIX 声明仅 Windows 目标）+ 矩阵文档化。
- **F2 模板 TS 变体（附带）**：vue-ts / react-ts / solid-ts / preact-ts（TS 绑定 import 已有基建）。

### v0.3.5 — 安全与系统深化

目标：安全模型收掉 Tauri 最后一个大项，Linux 现代会话支持补齐。

- **C2 isolation pattern**：`Config.isolation = { key, origins: [...] }`——随机 origin 沙箱
  iframe 持钥、主页面经 postMessage 代理、Zig 侧校验签名（对齐 Tauri 语义：
  远程页面拿到运行时也无法伪造有效调用）。验收：远程页面篡改 payload 冒烟必拒 +
  本地页面不受影响。
- **D1 Wayland portal 快捷键**：hotkey op 在 Wayland 会话（`WAYLAND_DISPLAY` 判定）改走
  GDBus `org.freedesktop.portal.GlobalShortcuts`（CreateSession → BindShortcuts → Activated）；
  X11 保持 XGrabKey。验收：代码路径单测 + CI（X11）skip 分支 + Wayland 会话手动验证记录。
- **D2 DPAPI 加密 store**：`Config.store.encrypted = true`（Windows）→ 值经
  `CryptProtectData(CRYPTPROTECT_UI_FORBIDDEN)`，落盘 `dpapi:` 前缀；跨进程读回断言。
  Linux：文档化（libsecret 列为 v0.4+）。
- **C3 附带**：绑定 codegen 保留参数名（注释提取列为 stretch）。

### v0.3.6 — IPC v2 + CompositionController

目标：两个体验升级大项（用户确认纳入）。

- **C1 原始二进制 IPC**：协议保持 JSON v1 为控制面，新增二进制载荷通道——
  Win：`ICoreWebView2Environment8::CreateSharedBuffer` + `postSharedBufferToWebview`
  （invoke 参数/返回值/Channel 数据可带 SharedBuffer 引用）；Linux：实测后定方案
  （evaluate BLOB / 分块 scheme）。接口：`invokeBinary` / channel 二进制模式。
  验收：10MB 传输对比（base64 vs shared buffer）CPU/耗时数据 + 单测 + 冒烟。
- **A11 WebView2 CompositionController**：`window.create({ composition: true })`——
  DirectComposition visual tree（`ICoreWebView2CompositionController::put_RootVisualTarget`）、
  输入转发（SendMouseInput + pointer 路由）、NonClientRegionSupport（app-region: drag CSS
  原生 hit-test：GetNonClientRegionAtPoint / add_NonClientRegionChanged）。
  验收：composition 窗口 overlay 标题栏拖动/吸附/Aero 对齐 + 冒烟 c-comp + 失败回退
  HWND 模式（运行时能力探测，对齐项目降级文化）。

### v0.3.7（弹性位）— server 模式

目标：对齐 Wails 的「浏览器客户端作为窗口」（远程 UI/多客户端场景）。

- **F1**：headless 升级——`ZILT_SERVER=1`：`/zilt/ws` 每连接一个会话 → `BrowserWindow(id)`
  进入窗口注册表（独立 id 空间）→ invoke 按 sender 路由（复用多窗口 per-window IPC 基建）→
  `emitTo(browserWindowId)` 可定向广播；页面级事件仅广播该会话。
  验收：双浏览器 tab 独立 invoke/事件路由 E2E（scripts/）+ GUI 回归零改动。

## 2. 验收链（沿用现有）

每版本统一：`zig build test`（单测增量）→ `zig build`（capability 清单 + 资产嵌入）→
GUI 冒烟（`ZILT_SMOKE_EXIT=1`，新增检查项逐版本 +1~3）→ headless/MCP E2E →
Linux 侧 `dev-smoke.sh`（Xvfb + openbox）→ 打包 E2E（涉及分发项时）→
Windows/Linux 双平台单测全绿 + README/ROADMAP/能力矩阵同步。

## 3. 风险与依赖

| 风险 | 缓解 |
|---|---|
| B1 的 EnvironmentOptions4 需 WebView2 较新运行时 | 运行时版本探测 + 伪路径协议回退（沿用透明窗口降级模式） |
| B2 IsPrivate 需 ControllerOptions API（运行时 1.0.1661+） | 能力探测降级 + 文档化最低运行时版本 |
| C1 SharedBuffer 是 Win 独有现代 API | Linux 方案实测后定；接口层抽象，单测锁协议语义 |
| A11 CompositionController 工程量大（DirectComposition + 输入转发） | 独立版本排期；失败回退 HWND 模式；Wails 源码（popupmenu_windows/worker_forwarding 同目录）可作行为参照 |
| D1 portal 需真 Wayland 会话 | CI X11 分支 skip + 手动验证记录（对齐 v0.2.5 Wayland 实测项） |
| E3 GitHub API 无鉴权限流 | provider 仅 check 用 releases/latest；Fetcher 注入离线单测 |
| F1 会话模型与安全（跨 origin WS） | 仅绑 127.0.0.1 + token 握手（沿用 headless 端口安全面） |
