系统能力 / 更新器（v0.1.2）

菜单栏：文件/帮助（点击触发 menu 事件）；全局快捷键：Ctrl+Alt+N / Ctrl+Alt+R / F7。

托盘：左键点击 = 显示/隐藏窗口，右键 = 弹出菜单（v0.1.6）；关闭按钮 = 隐藏到托盘。单实例保护已启用（第二实例参数转发后退出码 5）。

多窗口 / 窗口控制 / 剪贴板（v0.1.6）

把文件拖进窗口 → dropFiles 事件；从外部打开 zilt://… 或 .zilt 文件、再启动一次 exe（第二实例）→ deepLink 事件。

窗口模型 / 窗口事件（v0.1.7）

窗口移动/缩放/焦点/主题/DPI/关闭请求事件见上方输出； 透明窗口标题栏标记 data-zilt-drag-region 可拖动，Alt+F4 触发 windowCloseRequested 后由前端确认关闭。
